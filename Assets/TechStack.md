The project will be using Unity 6.6 and Meta Building Blocks.

Target Platform: Meta Quest 3 (Stand-alone VR/MR).

Core SDKs:
- Meta XR All-in-One SDK (Interaction, Core, MR Utility Kit).
- Meta Interaction SDK (Primary input/interaction framework).
- Universal Render Pipeline (URP) with World Space UI for all UXML/2D elements.
- NavMesh Components (for runtime baking on generated terrain).

All UI should be built in UI toolkit and use OVRoverlay to display the ui.
